# Hadoop para evaluar palabras

## Florence and the Machine y Florence Nightinale

Dos personas (una enfermera y un crítico de música) discuten acerca de un tema en particular:
la relativa sofisticación entre dos figuras aparentemente no relacionadas Florence and the
Machine (un grupo inglés de rock) y Florence Nightinale (una enfermera inglesa legendaria).
Para resolver la disputa se necesita contar la frecuencia de palabras mayores a seis letras en las
letras de las canciones de Florence and the Machine y los escritos de Florence Nightinale.
